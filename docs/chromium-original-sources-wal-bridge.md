# Original native source metadata to WAL

This partial primitive is unused by production. NativeOriginalSourcesPolicy is version0/empty, accepted caller/helper policies stay0/empty, and NativeVerifiedPhaseReceipt stays uninhabited. A diagnostic helper CodeDirectory pin is not an accepted source image. No settings, installation, close, full capture or EngineSwitchAuthority route is enabled.

The private Client receive lane now returns a private OriginalNativeDelivery containing the original factory counterpart, actual per-request SocketWriteTicket snapshot and arriving raw-envelope SHA. Public request() still returns only JSON. No public NativeGroupApprovalObservation/outcome parser or journal decoder can make a NativeOriginalSourcesReceipt. Its only constructor is fileprivate in Client.swift and its one caller requires the qualified original endpoint after actual full byte write and after native metadata decoding. A loaded WAL is historical metadata, never this receipt or a recreated native owner.

recordOriginalGroupSources requires an existing actual original counterpart, accepted exact source-qualified helper CodeDirectory, source SDK/manifest policy and native sources version1. Current policy refuses before WAL mutation/dispatch. It validates actual original peer evidence against immutable intent, reserves one of two non-evicting transaction credits, and retains credit after success, cancellation, timeout or loss. There is no resource retirement API in this packet. No third group can be admitted by removing an old map entry.

The command is generated by the original client actor, then used as BOTH actual wire request ID and native command. Socket constructs the private ticket from the exact encoded frame including newline. Before enqueue, the actual frame SHA/length and command enter immutable journal write-ahead under lock+CAS+fsync+exclusive rename+directory fsync. The client reobserves the actual original kernel/socket peer after that potentially long await. A canceled task cannot cause an automatic cancel, retry, new native owner or replacement connection.

| Durable phase | Meaning | Native authority |

| intent | User/owner metadata only | None |
| reserveDispatchPending | Exact original reserve command/frame may be dispatched | No inferred native reserve |

| cancelDispatchPending | Explicit metadata write-ahead only | No cancel dispatched by journal |
| unknown | Original loss/ambiguous result; retain pending/observed metadata | No retention/rollback/close claim |

Format2 retains format1 decoding/canonical bytes and bounded eight immutable revisions. Positive metadata CAS accepts only the private original receive-lane receipt and its exact intent/cursor/last sources command/frame. Loss remains one atomic latest-read+same immutableIntent+unknown-persist under the same lock. A concurrent latest positive metadata revision cannot escape original loss reconciliation. An incoming original-socket page.crash/tab.closed for a reserved original tab poisons source/journal before event delivery. This is negative uncertainty only; event tab labels never establish native ownership. Child-frame/source-tree withdrawal needs the future exact native group event bridge or a new authenticated native revalidation, so sourcesObserved remains historical metadata. Source loss never clears native owned resources, pending evidence or old file revisions. Filesystem staging uncertainty is retained and poisons further writes.

The real0064 producer supplies all-frame document/context/parent topology plus private0062 original renderer task-witness descriptions. Decoder requires exactly one matching main document per intended native browser, all child parents within the same browser/context, no missing parent/cycle/duplicate logical frame, stable native launch incarnation per logical renderer, and native witness version/birth/PID-version/boot/path/argv/code/audit metadata. Logical processId/routingId are tree keys, NEVER OS PID or signal authority. Chromium0062 uses uppercase base::HexEncode for argv/audit/code digests; Swift helper evidence uses lowercase, so the decoder preserves the separate native representation. Boot UUIDs match the original helper host semantically. Maximum4096 frames/256 native processes/3MiB typed tree fail as a whole, never truncate. Socket4MiB and existing helper3MiB metadata limits are unchanged.

WAL stores request/response/tree/group/source digests, exact native sequence strings and bounded native process-birth metadata. Raw source/group capabilities, Mach SEND rights, capture payload and settings bytes are not persisted or logged. JSON process descriptors cannot reconstruct native rights or authorize signaling. Native fullImageLease/atomic commit stay false. Source-process death after the native callback is not transformed into a promise that a document remains alive.
