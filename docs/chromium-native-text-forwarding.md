# Exact native IME adapter candidate

This consumer pack targets the frozen experimental0057 schema from owncef PATCH24 (same public schema as23). Source60/cache is unchanged. The native patch remains inactive, and helper production nativeTextFocus capability stays false: API presence is separate from YABCORE_NATIVE_TEXT_FOCUS_ACCEPTED_VERSION, which defaults0. Promotion to1 requires the exact future SDK's reviewed actual native compile/link/runtime receipt. No user RPC/test boolean enables that flag.

CEF browser header API is SendExternalTextInput(command,CefExternalTextInputCallback), whose OnExternalTextInputResult carries the exact original command/focus/document/frame/node/browser+renderer focus epochs and four UTF16 ranges, version1/status applied|rejected|unknown. Snapshot focusIdentityVersion1 is required and exists only after the native original renderer focus-stamp ACK. A focusToken, JS token, Swift localTurn or native text-state revision cannot substitute for it.

input.text.native accepts the flat exact command plus tab/profile. It validates types/ranges and original helper endpoint, invokes only SendExternalTextInput, and retains a bounded original pending record without text. It does not call FindView, input.send, JavaScript, finish-as-cancel or another input API. The native deadline is5s, helper10s and client15s. Helper timeout/browser retirement produces explicit unknown; it never retries/cancels or changes the original native operation. Only the first terminal response is written, outside native callback/close stacks.

ResultSource distinguishes native, native-dispatch-rejected, helper-browser-closed and helper-timeout. NativeAcknowledged is true only for an exact native callback. A native true dispatch return is not applied; false is before-effect rejection. The typed client accepts applied only for exact native ACK, matching original tab/profile and every command/ownership/range field. Caller cancellation after dispatch still consumes the independent original RPC result. Transport loss/timeout/malformed result is unknown, and the client poisons that exact tab/profile/native focus identity until a genuinely new native stamp is used. It does not reconnect, retry or poison a later focus from an old ACK.

The exact native callback additionally writes a bounded YAB_NATIVE_TEXT_ACK trace of command/status/exact/afterHelperTerminal, without text. This trace is emitted only by the actual CEF callback, even if a helper terminal unknown was already delivered. A helper OnBeforeClose/timeout unknown is not proof that the native destructor drained its registry. Late native ACK cannot write a second RPC.

Pending-teardown acceptance must obtain an original real renderer stamp, block the original renderer2s with a fixture beacon, queue a real native IME command, then close the original browser. Require the actual native unknown callback before5s and exactly once; retain late callback trace and source provenance. Other required actual cases include first Cocoa character, input/textarea/contenteditable and cross-origin iframe, emoji/Japanese ranges, native replacement/unmark/real cancel, same-node blur/refocus ABA, navigation before receiver use, synchronous focus/doc drift from each original input event, wrong owner/token/replay, native/helper timeout and whole process loss. Plugin/EditContext are explicit source rejections and remain native parity gaps.

The typed Swift suites are controlled adapter receipts only, not native acceptance. The current page's legacy Cocoa route remains separate while native capability is unavailable. Before activation, its page input queue must capture the real stamped identity, use only this exact route when supported, update client composition only from the owned outcome, retain unknown safely and never fall back after dispatch. Initial native focus echo lag/first Cocoa insertion still needs the separate original-site prepared-app experiment. This pack alone does not claim full PAGE IME or safe switching authority.

A rejected outcome requires the exact native ACK or explicit native-dispatch-rejected before-effect provenance. Helper timeout, retirement, malformed or missing provenance is unknown. The connection retains at most256 uncertain editing endpoints; reaching the bound permanently disables forwarding on that client, without evicting old poison or retargeting replacement focus.
