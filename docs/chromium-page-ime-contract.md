# Native page input method probe

The disposable bench route is `do=chromium, op=native-ime`. It invokes the actual `ChromiumPage` NSTextInputClient methods. `action=state` is read-only. `mark`, `commit` and `finish` require exact `remote` (String), `localTurn` (Int), `focusToken` (String) from that page's preceding state. The page must be the key window's actual first responder. `mark` additionally takes `text`, `selectionStart`, `selectionLength` in UTF16 units. `commit` takes `text`. `finish` invokes `unmarkText`, which commits the current native composition. Replacement ranges remain NSNotFound, as in the current product bridge. `cancel` reports `dispatched=false, unavailable=native-cancel-document-lease` and does not call finish.

State returns `remote`, `localTurn`, `localGeneration`, `live`, `focused`, `focusToken`, `nativeRevision`, raw `nativeState`, `hasMarkedText`, `markedRange` and `selectedRange` as `{location:Int|null,length:Int}`. `caret` is `[x,y,width,height]` in `screenBottomLeft` AppKit coordinates. `geometrySource=native` requires original root-page native caret metadata; a fallback view rectangle is labeled fallback. Raw nativeState geometry is root-page DIP with a top-left origin.

`dispatchTicket` and `dispatchResult` describe only the exact queued command. An earlier command cannot acknowledge this command. `dispatchResult=unknown` or `queued` yields `dispatched=null`; a refused or absent command yields false. `dispatched=true` is only this command's completed helper RPC. The native snapshot explicitly does not acknowledge renderer input processing. The probe must independently observe changed raw native revision and original trusted renderer composition/input events. The endpoint always reports `nativeAcknowledged=false`, `nativeLease=false`, `documentProof=unavailable`. Swift local generation/turn and native focusToken must never be used as a substitute for an original native DocumentToken/frame lease.

The production local cache now clears on helper loss, document navigation/commit, retirement, focus withdrawal or a native editing target change/cancellation. Queued IME operations retain only the already connected client, original remote and local epoch/turn/generation/focus; they cannot launch endpoint(), or deliberately carry a cached composition into a known replacement. A native in-flight forwarding race remains unproven and is not accepted by this guard.

The current helper input.send finds a RenderWidgetHostViewCocoa recursively. Its dispatch is insufficient for strict focused-document ownership. The stock windowless CefBrowserHost Ime* functions are NOTIMPLEMENTED in ChromeBrowserHostImpl. A separate source candidate must use the existing native HasNativeTarget/MatchesFocus checks, original focused RFH DocumentToken/GetDevToolsFrameToken and actual active TextInputManager widget; it must additionally validate on the original renderer receiver and return an exact applied/refused ACK. No FindView fallback may provide that capability. This followup must not mutate the active SDK build. Until its actual runtime proof, PAGE IME, native cancel and strict stale-document behavior remain active R1 gaps.

The local suites exercise invalidation and negative admission only. They are not native runtime acceptance.
