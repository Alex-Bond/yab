# WK original beforeunload intent experiment

This test-only packet adds one native scenario alongside the unchanged ordinary Stay/Leave cases. It does not implement ProductionAuthority or a reusable WK approval token. Actual app/runtime NOT_RUN.

A real native WK document receives trusted AppKit keys; quiet reads must show no initial sticky activation, then trusted original input. The direct original _tryClose must enter the asynchronous native path. A test-only UIDelegate forwards that ORIGINAL native beforeunload to Browser's real PageAsk. The user selects Leave through Browser.answer; the observer records the actual initiating FrameInfo documentUUID and answers the ORIGINAL WK completion false. No Leaving.Wait/patience timeout or synthetic finish supplies this observation. Native false is recorded as false, not renamed Leave approval. All other original adapter callbacks stay forwarded. An unexpected webViewDidClose is counted and forwarded rather than hidden.

After the native response, the fixture requires the SAME native documentUUID, timeOrigin, original marker and typed draft, exactly one beforeunload, no unload or native close callback, and actual Undo changes the draft followed by actual Redo restoring it. These checks distinguish a dispatched false completion from observed original-document/Undo behavior. The original normal Stay and Leave modes keep their native decisions and all existing assertions.

Primary source inspection pinned at `f30181435991eca32b6abc25ed92d2cd49c724c6`:

- `_suspendPage:`/`_resumePage:` exist in the private interface and forward to the page proxy. This establishes an available upstream SPI declaration, not installed runtime selector proof. [WKWebViewPrivate.h](https://github.com/WebKit/WebKit/blob/f30181435991eca32b6abc25ed92d2cd49c724c6/Source/WebKit/UIProcess/API/Cocoa/WKWebViewPrivate.h#L560), [WKWebView.mm](https://github.com/WebKit/WebKit/blob/f30181435991eca32b6abc25ed92d2cd49c724c6/Source/WebKit/UIProcess/API/Cocoa/WKWebView.mm#L5533).
- Proxy suspend aggregates replies from its web-content processes. tryClose may return immediately for sudden termination, otherwise uses native TryClose; a true response or timeout invokes closePage, which clears edit commands before the UI close callback. That matches the earlier measured native Leave/Undo loss. [WebPageProxy.cpp](https://github.com/WebKit/WebKit/blob/f30181435991eca32b6abc25ed92d2cd49c724c6/Source/WebKit/UIProcess/WebPageProxy.cpp#L2138), [closePage](https://github.com/WebKit/WebKit/blob/f30181435991eca32b6abc25ed92d2cd49c724c6/Source/WebKit/UIProcess/WebPageProxy.cpp#L12705), [suspend](https://github.com/WebKit/WebKit/blob/f30181435991eca32b6abc25ed92d2cd49c724c6/Source/WebKit/UIProcess/WebPageProxy.cpp#L7267).
- WebProcess tryClose asks the native loader shouldClose. Its suspend freezes the layer tree, caches the page and detaches opened frames. [WebPage.cpp](https://github.com/WebKit/WebKit/blob/f30181435991eca32b6abc25ed92d2cd49c724c6/Source/WebKit/WebProcess/WebPage/WebPage.cpp#L2496), [suspend](https://github.com/WebKit/WebKit/blob/f30181435991eca32b6abc25ed92d2cd49c724c6/Source/WebKit/WebProcess/WebPage/WebPage.cpp#L5167).
- Cache suspension stops loads, can move focus, fires pagehide before caching, then freezes the document state. Therefore using it as a neutral retained-original seal would be an unsupported inference. [BackForwardCache.cpp](https://github.com/WebKit/WebKit/blob/f30181435991eca32b6abc25ed92d2cd49c724c6/Source/WebCore/history/BackForwardCache.cpp#L505).
- Inspected injected-bundle APIs expose frame/scroll/JS interfaces and warn that parent/children can be in other processes; they did not provide the required quiet shouldClose-only plus all-frame native capture/seal authority. This is an inspection result for these headers, not a claim that no private API could exist elsewhere. [WKBundleFrame.h](https://github.com/WebKit/WebKit/blob/f30181435991eca32b6abc25ed92d2cd49c724c6/Source/WebKit/WebProcess/InjectedBundle/API/c/WKBundleFrame.h#L42), [WKBundlePagePrivate.h](https://github.com/WebKit/WebKit/blob/f30181435991eca32b6abc25ed92d2cd49c724c6/Source/WebKit/WebProcess/InjectedBundle/API/c/WKBundlePagePrivate.h).

The installed Xcode WebKit.tbd was read-only inspected: WKPageTryClose and WKBundlePageSetDefersLoading are exported, but this does not prove private Objective-C selectors or semantic behavior. Native runtime inventory, if later required, must be a separate root-owned read-only job. No native call/UI/build/farm job/signing was run here.
