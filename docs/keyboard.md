# Keyboard

| | |
|---|---|
| `⌘L` address · `⌘K` switch tab · `⌘T` new tab · `⌘W` close · `⇧⌘T` reopen | `⌘[` `⌘]` back, forward · `⇧⌘[` `⇧⌘]` previous, next tab · `⌘1`–`⌘9` jump |
| `⇧⌘S` tabs across the top or down the left · `⌘S` hide them · `⌘D` keep the tab · `⌥⌘B` bookmarks | `⌥⌘R` reading mode · `⇧⌘P` float the video · `⇧⌘H` hide something · `⌘E` site controls, what is hidden here among them |
| `⌘F` find · `⌃⇥` last tab · `⇧⌘C` copy address · `⇧⌘V` paste and go | `⌘Y` history · `⇧⌘J` downloads · `⌘,` settings · `⌥⌘L` passwords |

`Tab` is the page's, as in every browser, and walks the list in the field; `esc` puts away whatever is open. A page that keeps `⌘S`, `⌘[` or `⌘]` for itself is told so in the corner, and the same key again is Yab's. In the field, `⌘K` lists what can be done to the chosen row, and `⇧⌘K` (the round button at its foot's left) is the About menu: feedback, the changelog, the keys, About and Settings.
